# Discovery & SEO Architecture

Search Engine Optimization (SEO) and programmatic local discovery are not supplementary marketing tactics for Flour n Sugar; they are core architectural pillars designed into the routing and rendering pipeline.

---

## Canonical URL Hierarchy

The platform exposes an indexed, crawlable, and semantic URL structure:

```text
/                                    -> Global Landing Page
/bakers                              -> National Baker Directory
/bakers/[store-slug]                 -> Direct Baker Storefront (/cakesncookies)

/categories                          -> Global Category Directory
/categories/[category-slug]          -> Global Category Listing (/categories/sourdough)

/locations                           -> City & State Directory
/locations/[city-slug]               -> City Landing Page (/locations/lucknow)
/locations/[city-slug]/bakers        -> City Baker Directory (/locations/lucknow/bakers)
/locations/[city-slug]/[category]    -> Programmatic Local Category (/locations/lucknow/eggless-cakes)

/products/[product-slug]             -> Featured Product Detail View
```

## Programmatic Local SEO Engine

By combining geographic locations with baking categories, Flour n Sugar systematically targets high-intent long-tail search queries:

| Search Intent | Target Programmatic Route | Dynamic Page Title |
| :--- | :--- | :--- |
| "Home bakers in Lucknow" | `/locations/lucknow/bakers` | Top Home Bakers & Bakeries in Lucknow \| Flour n Sugar |
| "Eggless cakes in Noida" | `/locations/noida/eggless-cakes` | Best Eggless Cakes in Noida — Order from Local Bakers |
| "Sourdough bread Bangalore" | `/locations/bangalore/sourdough` | Artisanal Sourdough Bread in Bangalore \| Local Bakers |
| "Custom birthday cakes Jaipur" | `/locations/jaipur/custom-cakes` | Custom Birthday Cakes in Jaipur \| Portfolios & Prices |

## Performance & Core Web Vitals Targets

Search engines heavily penalize slow-loading pages, especially on mobile networks in India. Public routes must meet strict thresholds:

* **LCP (Largest Contentful Paint):** `< 2.0s` (Aggressive WebP image optimization via Cloudflare R2 + CDN).
* **CLS (Cumulative Layout Shift):** `< 0.05` (Explicit aspect-ratio containers for all product images).
* **FID / INP (Interaction to Next Paint):** `< 100ms` (Zero heavy client-side JavaScript execution on initial page load).
* **Static Generation (SSG / ISR):** Public city directories and storefront profiles are statically pre-rendered and revalidated on background updates.
